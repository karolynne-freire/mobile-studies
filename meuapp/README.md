# 🎵 MeuApp

Aplicativo mobile desenvolvido com **React Native** e **Expo** como parte dos estudos de desenvolvimento de aplicativos.

## 📱 Sobre o projeto

O **MeuApp** é uma aplicação simples desenvolvida para praticar os conceitos básicos do React Native.

O aplicativo apresenta o grupo **BTS**, exibindo imagens, título e um botão de interação.

## 🚀 Tecnologias utilizadas

* React Native
* Expo
* JavaScript
* React Native Elements
* Expo Status Bar

## ✨ Funcionalidades

* Exibição do título **BTS**
* Carregamento de imagens através de URLs externas
* Indicador de carregamento das imagens
* Rolagem da tela com `ScrollView`
* Botão **Learn More**
* Estilização utilizando `StyleSheet`

## ⚙️ Como executar

### 1. Instale as dependências

Depois de clonar ou baixar o projeto, entre na pasta:

```bash
cd meuapp
```

Instale as dependências:

```bash
npm install
```

### 2. Inicie o projeto

Execute:

```bash
npx expo start
```

Também é possível iniciar utilizando o modo LAN:

```bash
npx expo start --tunnel
```

## 📱 Executando no celular

Para executar o aplicativo em um celular:

1. Instale o **Expo Go**.
2. Inicie o projeto com `npx expo start`.
3. Conecte o computador e o celular à mesma rede Wi-Fi.
4. Escaneie o QR Code exibido pelo Expo.
5. Abra o projeto no Expo Go.

## 🖼️ Imagens

As imagens do aplicativo são carregadas utilizando URLs externas.

O projeto utiliza o componente `Image` do **React Native Elements** para exibir as imagens e o `ActivityIndicator` como indicador de carregamento.
